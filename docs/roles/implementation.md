# Implementation brief

Complete the assigned bounded story. Read the issue, its relevant decisions and
technical references, and applicable verification requirements. Do not load unrelated
role procedures or reconstruct the entire parent conversation.

- Establish the accepted scope and criteria. If a consequential ambiguity or change
  arises, record it and return it to the coordinator for Chandler's decision.
- Perform the investigation or changes, update lasting knowledge, and run relevant
  checks. Keep useful negative findings, failed experiments, and unresolved limits.
- Preserve the current assignment's history. Report blockers with a clear cause and
  observable unblock condition; do not delete cancelled or superseded records.
- Return the exact changed revision, outcome against each criterion, verification
  procedure and evidence, required review context, and any remaining blockers.
- Associate claims with the revision and environment checked. Planned checks, fixture
  tests, and live behavior are different kinds of evidence.

Self-review does not replace the separate reviewer. Do not approve your own result as
the independent reviewer or claim completion before required review and integration.
Routine review corrections stay within the accepted story's scope.

Return the result to the trusted host for review and integration. The host manually
dispatches the separate reviewer and applies Project transitions. Do not publish the
reviewer's Independent review check or treat a zero native required-approval count as
permission to omit review: integration requires the reviewer App's current-head check
and Workflow checks from GitHub Actions, as specified in [workflow](../workflow.md#done).

Use only the supplied implementation authority. It must not satisfy independent review
as the same identity, bypass required integration checks, reach owner or reviewer
credentials, or invoke the trusted host launcher. The accepted container arrangement
must be implemented and tested before these restrictions can be claimed as enforced.
